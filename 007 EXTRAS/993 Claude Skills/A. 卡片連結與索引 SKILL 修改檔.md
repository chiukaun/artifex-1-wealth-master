
# 卡片連結與索引 SKILL

## 任務

把一批正文已經寫好的卡片，**一張一張**歸檔進筆記網絡——建立連結、長出索引頁。

## 前提：輸入的卡必須是「乾淨的單一主張卡」

這個 SKILL 吃的是正文寫好、**講一件事**的卡。遇到以下狀況，退回、不要硬歸檔：

- **殘卡**：只有一兩行、沒套模板、標題跟內文對不上 → 退回，請補成完整的卡。
- **清單卡**：一張卡裡塞了三五個並列的主張 → 退回，建議拆成數張單一主張的卡。

對話發生在主張之間。一張卡沒有一個清楚的主張，就找不到它真正該連的地方。


## 針對每一張卡片的操作迴圈

對每一張要歸檔的卡 **C**，做這四件事，然後換下一張：

### 1. 筆記盒漫步

讀卡 C 的核心**主張**（主張，不是主題——對話發生在主張之間），然後開始筆記盒漫步。

筆記盒漫步方法如下：

展開 ATLAS 資料夾中所有索引頁，判斷這張卡片有機會歸檔進去哪一個索引頁中（可以選擇多於一個索引頁）。

找到候選索引頁之後，從索引頁裡面的關鍵字與入口卡標題找到最可能相關的入口卡（可以一次讀取多張，進入多個主線串）。

讀取入口卡之後，從入口卡出發當起點，不斷讀取「延伸區」建立的卡片連結 wikilink，直到邊界枯竭。試著猜測：「哪一個連結的卡片，最有可能跟卡 C 發生對話？」用這個問題一張一張往下漫步探索。

**永遠進行漫步，不准一次讀全域檔名清單。** 這個做法無法規模化，未來卡片筆記盒可能會超過 5000 張卡片，你無法一次讀完 5000 張。


### 2. 建立連結

一邊讀取，一邊問：在你讀過的候選卡片裡，有沒有一張卡 X，讓「讀完 X 會自然接著讀到 C」？C 是不是在**展開／回答／細化／承接** X？如果有，X 就是 C 的前一張。在 **X 的延伸區**寫一條引路詞與 wikilink，指向 C。

只要情況允許，盡可能讀取大約 20 張卡片，你可以走多個主線串、從多個索引頁關鍵字與多個入口卡進入，重點是讀夠深入，往下探索夠多層（展開夠多次連結卡片），不要只讀兩三層就建立連結。你必須真的找到「有發生對話」的連接卡，不是強硬加上連結。

你可能會找到多個連接卡 X。基於多重儲存原則，你可以把卡 C 建立連結在多於一個卡 X 上。只要你認定有產生對話關係就可以建立連結，但不需要勉強自己建立多重連結，確保只有在真的發生對話的時候才建立連結。

如果你讀完這一輪（不重複卡超過 20 張／邊界自然枯竭），沒有發現任何可以跟卡 C 產生對話的連接卡，那就更換別的索引頁，讀取別的關鍵字與入口卡，開啟另一輪探索。

如果你找不到任何入口卡進入的主線串可以跟卡 C 建立關係（這很有可能發生），那卡 C 就是一張入口卡。在跟卡 C 相關的索引頁中，建立新的關鍵字

如果目前沒有索引頁可以跟卡 C 產生潛在連結對話關係（或者 ATLAS 資料夾全空），那就根據卡 C 的內容，創立一個新索引頁，在該索引頁中成立新的關鍵字，並且以卡 C 為入口卡。索引頁與關鍵字相關規範寫於下面。


### 3. 卡片整理作業

當你把卡 C 做好連結之後，把卡 C 的標題加上數字編號 `N. (卡片標題)`，該數字編號 N 即為索引頁編號的 `Index N - （索引頁標題）`。

並且把卡 C 位置從 `/001 INBOX` 移動到 `/005 CARDS` 資料夾中。

### 4. 進入下一張卡 C

為了節省資源，當你處理下一張卡 C 時，你可以優先用你上一輪筆記盒漫步已經讀取過的內容，去判斷是否有產生對話的卡片。

如果沒有（很高機會沒有），那就重新進入 1. 開啟筆記盒漫步。


## 兩種連結（這是背景概念，不寫進卡片）

- **主線串**：思路的主線。一張卡接在另一張後面，順著同一個想法往下。允許顯而易見，理所當然的連結，「主線串」的工作是當**形成主要思路**。
- **撞見**：跨脈絡的跳接。把兩張不在同一條主線串、卻偷偷有對話的卡接起來。它的工作是當**意想不到的連結**。

⚠️ **每條 link 都是箭頭，從上游指向下游。** 上游 = 你站的位置／更基礎的觀察／從索引頁出發；下游 = 你從這裡看出去的延伸／更具體的應用。一條連結只寫在**上游卡**的延伸區，不在下游卡那邊回指一條來「對應」。網絡的乾淨來自「每條 link 只存在於一個位置」——雙向冗餘看起來很完整，實際上是噪音。撞見有極少數「反方向走過去也成立」的例外，見第 3 步——但例外要特別判斷出來，不是反射動作。

⚠️「主線串」「撞見」這兩個字、以及任何分類標籤，都不進卡片。延伸區只有引路詞 ＋ wikilink。

## 核心做法：一張一張處理

**處理卡片時，沒有「批」這個單位。** 卡片永遠是一張一張處理。處理到第 5 張時，前面 4 張（已歸檔的）就跟任何舊卡一樣，是「既有的卡」——它們不因為「跟第 5 張同一批萃取出來」就比較特別。

因為「同一批」是卡片被送來的方式，不是想法之間的關係。一張新卡真正該接的地方，可能是同一批的另一張新卡、也可能是三年前的舊卡——一張一張處理，才不會偏袒同一批。

→ 所以「主線串」不是一個你動手做的步驟，是一張一張歸檔之後、**自然長出來的形狀**。

→ 處理順序不影響結果的對錯：「前一張」是脈絡下的選擇，不是等著被找到的真相。不同順序長出不同但都有效的骨幹；真實的關係不會掉，串沒接到的，撞見會接住。


## 引路詞怎麼寫

每條連結，wikilink 上面寫一行引路詞。第一人稱、白話、順著講，用加恩的語氣（MSN 聊天室那種輕鬆感）。**不寫對話類型標籤。**

寫完引路詞，回頭看一眼——這條引路詞是不是要動「反過來看／換個角度／同一個東西的兩面／另一面」這類**視角轉換語言**才寫得通？或者得把舊卡的主張**縮窄／曲解**（「原本以為 X 只是⋯，沒想到 X 也是⋯」）才能讓兩張卡咬合？

是的話 → 這是**主題撞**，不是**對話撞**：兩張卡只是共用一個主詞（人名／概念／工具），但主張之間沒有具體咬合的位置——你是在替它們編 framing、當中介，不是它們自己對話。**拿掉這條。**

對照「對話撞」長什麼樣：A 卡的某個位置剛好補上 B 卡的某個位置，或 A 是 B 的反例、同源動作、補位視角。引路詞會自然指出那個具體咬合點，不需要視角轉換語言、也不需要把任何一張卡的主張改寫。

## 延伸區格式

延伸區是這張卡**往外指**的地方，不是往回追溯的地方。所以這裡會放：
- **串-link**：作為 X，指向接在自己後面的 C（「下一張接到⋯」）
- **撞見-link**：作為跨脈絡跳接的起點，指向其他卡

兩者在實際做連結時不會有任何標示區分，只是注意在做連結時，除了合理顯見，理所當然的連結以外，也要尋找那些意想不到的「跨脈絡連結」。

⚠️ **延伸區裡不放「回指前一張」的 link。** 動手前自問：我寫的這條 link 是「往後」（指向接在我後面的卡）還是「往回」（指向我接在誰後面）？只有往後的該寫。

```
#### 延伸
---

（引路詞）
[[往下連接的卡片]]

（引路詞）
[[跨脈絡跳躍連接的卡]]

`CREATED:: ⋯
```


延伸區也可能留空，意味著這張卡片是尾端、沒有跨脈絡連結，這是正常的。

## 索引頁與關鍵字格式

```
關鍵字
[[入口卡]]

關鍵字
[[入口卡 1]]
[[入口卡 2]]
```

索引頁的名稱應該指向一塊大領域，不可以用太過具體或限縮的概念作為索引頁標題。魯曼九萬多張卡片，可能索引頁才幾十張而已。

索引頁必須節儉開立，當你今天發現你手上的卡 C 必須創建新的關鍵字，而該關鍵字怎樣都無法放在現有的索引頁裡面時，才能開設新的索引頁。

索引頁中的關鍵字，也是通稱廣泛概念的字詞，例如經濟學下的「機會成本」、「匯率」、「央行」...等，不可以是過度具體的小概念。關鍵字通常會是這個領域中的「非常重要的概念」，例如「複利」、「風險」之於投資，是領域中的核心概念。想像這個更像是下標籤的時候會用的關鍵字，你只是沒有使用 # 符號。

⚠️ 新關鍵字要省著開。開之前先問：**這個關鍵字跟某個既有的、或這輪剛開的另一個，是不是同一個「把手」——回答的是不是同一個問題？**

- 是 → 不要分兩個。併成一個關鍵字，底下掛多張入口卡（每張導向不同分支）。
- 判準：若一個關鍵字是另一個的子類、或兩者一起回答同一個問題（例如「框架」與「原則」都在回答『一篇文章的結構怎麼安排』），那就是同一個把手。

⚠️ 一次歸檔多張卡時特別容易犯：每張各自「既有關鍵字裝不下」就各開一個，結果開出一堆其實同源的窄關鍵字。**新關鍵字彼此之間也要互比**，不只比既有的。寧可一個寬把手掛 2～4 張入口卡，不要切成兩三個窄把手——原則五的精神是收斂成少數把手，不是貼合內容的每個分支。

關鍵字是**概念**，不是句子（「脈絡」，不是「AI 是上下文預測模型」）。耐久的把手——背後的入口卡可以換，關鍵字不動。



## 收尾一：順向遊走驗證

跑完所有 per-card 迴圈之後、回報之前，**強制做一次**：

從這輪歸檔的每張新卡所連到的最上游入口卡出發，**只順著延伸區的箭頭往下走**，能不能走到所有這輪歸檔的新卡？

- 走得到 → OK。
- 走不到某張新卡 → 某張上游卡的延伸區漏了一條指向它的 link。回頭補。

這條動作專門擋一種錯：自己腦中以為「網絡長好了」（因為所有新卡都認回了上游），但上游卡的延伸區沒被擴增，從入口走不出去。指向性是單向的——下游認回上游不代表上游能走到下游。

## 收尾二：索引頁 MECE 檢查

順向遊走驗證跑完之後，再看一次這輪碰過的索引頁。
整理索引頁只有一條原則：MECE——不重複、不冗餘，但完整涵蓋整個筆記盒。

**索引頁之間**——兩個索引頁不可以重複涵蓋同一塊大領域。索引頁之間底下的關鍵字也不應該重複，如果有近似觀念但是切角不同，那沒有關係。但如果有重複關鍵字，應該併在其中一個索引頁就好。

**索引頁之內**——兩個關鍵字不該是同一個把手（判準見上面「新關鍵字要省著開」）。同一張入口卡也不該同時掛在兩個關鍵字底下。如果有關鍵字下面連結到的卡片越來越多，多到有些腫脹的感覺，那可以考慮分出來獨立成為索引頁。但這必須是非常明顯的狀態下才做的決定。

**關鍵字之內**——入口卡超過 4 張就是冗餘。砍到 1~4 張，每張導向不同分支。


### 動到既有卡片編號的時候

關鍵字升格、或卡片改掛到別的索引頁，檔名前綴要跟著改（直接 `mv`，見 CLAUDE.md 編碼前綴規則）。改完**全 vault 搜一次舊檔名，更新所有 wikilink**——包含其他卡片的延伸區跟所有索引頁。漏一條就是斷鏈。

⚠️ 這裡動的是索引頁上的一行、跟卡片的編號。**卡片一張都沒少。** 原則四管的是卡片，不是索引。


## 回報

跑完一輪 ＋ 順向遊走驗證之後，逐張卡回報：

- 接到哪條串的哪張卡（或成為新源頭）。
- 建了哪些撞見。其中「拿不準但好像有機會」才建的，點出來，讓加恩看見、有需要再回頭調整。（不要回報「砍掉了什麼」——預設從寬，沒有砍這個動作。）
- 有沒有長出新關鍵字；若併了關鍵字、或猶豫過要不要新開，說一聲。

整理如果動到索引頁既有結構，單獨列一段：升格／合併了什麼、改了哪幾張卡的編號、更新了哪些檔案的引用。
