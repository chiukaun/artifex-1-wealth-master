## 1. 核心命題

> 由上而下，由下而上，個人面對心魔與突破，**累積出來的價值觀是雙向擠壓之下的鑽石**。

個人專案系統存在的真正理由：把面對心魔的過程變成可視化、可推進、可累積的工作。心魔最會做的就是打模糊仗讓你看不清楚對手是誰；藉由寫作可視化，問題會變清晰。

### 雙向擠壓的鑽石

兩股力量擠壓——

- **由上而下**：命盤折射出「我是誰」的定義 → 呈現出「我希望我是誰」的嚮往
- **由下而上**：每一個面對心魔的個人專案 → 一步一步走向那個嚮往

兩端之間的擠壓，會慢慢沉澱出價值觀——這就是鑽石。

### Fractal（自相似）結構

雙向擠壓在兩個層級上都成立——

```
                 🪞 我是誰／🧭 生命觀／🎸 興趣
                 「我希望我是誰」（嚮往）
                          ▲
                          │ ← 一步步走向嚮往
                          │
─── DASHBOARD 累積層 ───────────
       🚫 我不要的    🔥 我活出來的
       （鑽石的兩面切片）
                          ▲
                          │ ← 月度回顧撈候選認領
                          │
─── DASHBOARD 操作層 ───────────
       個人專案
        [F.][F.][F.]
            │
            ▼ 進入單一 WORKBOOK
            
      ┌─── 個人 WORKBOOK 內 ──────┐
      │  🌅 嚮往端                │
      │       ▲                  │
      │       │ 擠壓              │
      │       ▼                  │
      │  🌑 心魔端                │
      │  🌀 擠壓中（思考中）       │
      │  💎 鑽石（領悟）  ──────┐ │
      └────────────────────────┘
                                ▼
            月度回流到 DASHBOARD 累積層
```

DASHBOARD 是主結構，WORKBOOK 是子結構，鑽石的資訊流順著從子流到主。

### 三重螺旋裡的位置

對應 [[000 工作專案系統藍圖]] 的 triskelion——個人專案系統管的是**面對心魔／玩樂**這條腿。

```
              學習 🧠
           （卡片筆記）
              ↻
            ↗   ↘
   工作 🔧  → → →   ❤️ 個人  ← 這份藍圖
  （專案筆記）   （個人專案系統）
```

工作是建造、學習是吸收、個人是化解心魔。三條腿互相纏繞——某些工作專案的心魔，可能就是某個個人專案要解的；某些個人突破，會反過來餵給工作的方向。

### 設計核心：降低操作摩擦，保留判斷摩擦

跟 [[000 工作專案系統藍圖]] 共享同一條哲學——AI 越會做的事就讓 AI 做（撈候選、算剩餘天數），使用者越該掙扎的事就留給使用者掙扎（認領鑽石、決定過期雜事要延期還是放棄）。

## 2. 為什麼用流速分層

DASHBOARD 三層的分層判準是**資訊流速**——這個資訊多久動一次：

```
定義層 ─── 流速最慢（很少改／命盤級的東西）
累積層 ─── 每月更新一次（月度回顧時撈鑽石）
操作層 ─── 最快（隨時動／生活雜事每天動）
```

用流速當判準，避開了「重要性」「抽象度」這種容易吵的維度——這個資訊多久動一次，是物理事實，不需要爭辯。

打開 DASHBOARD 第一眼看到的是定義層（**先被自己接住**），不是被待辦事項追著跑。

### 設計原則：DASHBOARD 是萃取層，不放原始材料

DASHBOARD 上的所有內容，都應該是「從原始材料萃取出來的東西」——不是把原始材料本身搬上來。原始材料留在累積檔（自由寫作、WORKBOOK 鑽石、累積檔），DASHBOARD 只呈現凝練後的觀察、認領後的條目、萃取後的描述。

例：
- 「▋ 最近喜歡的自己」放**萃取後的自我描述**（fu-pan 從 [[【 F. 我喜歡自己的什麼 】]] 萃取），不是把原始 entry 列上去
- 「🚫 我不要的／🔥 我活出來的」放**使用者認領的條目**（fu-pan 撈候選 → 認領），不是把所有候選列上去
- 「🪞 最近的我 - 本週咒語」放**復盤討論後的咒語**，不是把整週狀態列上去

這個原則讓 DASHBOARD 一打開就被有意義的東西接住，不被原始噪音淹沒。

## 3. 三層架構

### 3.1 定義層（流速最慢）

從命盤萃取出來的自我認識。很少改，但走過的路可能會回頭改寫它。

| Callout | 放什麼 |
|---|---|
| 🪞 我是誰 | 命盤萃取的核心身份：我是什麼、擅長什麼、允許自己什麼 |
| 🧭 生命觀 | 三套命理系統共同指向的信念。第一人稱寫——「我相信」不是「命盤說」 |
| 🎸 興趣 | 命盤暗示的方向＋現在有在玩的 |

### 3.2 累積層（每月更新）

兩把哲學刀運作——

- **Via Negativa（否定之路）**：透過否定來定義。試過、確認不是自己的，一條一條削掉。雕刻家把石頭削掉，雕像就出來了。
- **Existence precedes Essence（存在先於本質）**：透過活過的來定義。事件、句子、能力——你活過什麼，就定義了你是誰。

| Callout | 放什麼 |
|---|---|
| 🚫 我不要的 | 試過、確認不是自己的東西。每一條劃掉的都讓輪廓更清楚 |
| 🔥 我活出來的 | 事件／句子／能力，活過的證據 |

兩把刀一起用——一個減法、一個加法——輪廓就出來了。

寫入格式：`- **{標題或句子}** —— {說明} —— YYYY-MM 出處`

例：`- **「那個瞬間我知道這就是我要的」** —— 2026-04 自由寫作`

### 3.3 操作層（最快）

四個 callout：

| Callout  | 放什麼                             | 流速  |
| -------- | ------------------------------- | --- |
| 個人專案     | WORKBOOK 對應式（每個專案一個檔案）。**不用燈號** | 不定時 |
| 🪞 最近的我  | fu-pan 寫入兩段：「本週咒語」＋「▋ 最近喜歡的自己」自我描述（皆覆蓋式更新） | 每週  |
| 📋 生活雜事  | 任務清單，每項要有死線                     | 每日  |
| 💬 AI 指令 | 給 AI 看的當前個人脈絡指引                 | 不定時 |

「🪞 最近的我」的「▋ 最近喜歡的自己」資料來源是 [[【 F. 我喜歡自己的什麼 】]] 累積檔（free-writing-extract 每次整理自由寫作時 append 原始 entry，fu-pan 復盤時讀整週新增萃取成自我描述）。**DASHBOARD 上只放萃取結果，不列原始 entry**——對應第 2 章「DASHBOARD 是萃取層」原則。

**個人專案區塊呈現**：

```
個人專案
- [[F. 拖延的根源]]——XX 描述
- [[F. 親密關係的距離]]——XX 描述
```

不用 orbit 燈號——個人專案步調比工作慢，用「最近有沒有推進」就夠了。

## 4. 個人 WORKBOOK 結構

跟工作 WORKBOOK **不一樣**。內部也是雙向擠壓的 fractal——這個專案要解的心魔是什麼、突破之後想成為什麼、當下擠壓進度、累積出來的鑽石。

### 結構

```
---
type: 個人
last_updated: YYYY-MM-DD
---

> [!info] **📍 現況**
> 一句話描述這個擠壓現在在哪

> [!example] **▶️ 下一步**
> 怎麼推進這次擠壓

---

> [!tip] **🌅 嚮往端**
> 突破之後想成為的樣子

> [!warning] **🌑 心魔端**
> 要面對的恐懼／模式／抗拒

---

> [!question]- 🌀 擠壓中
> 當下的拉扯、實驗、卡住的地方
> - 標 🔴／🟡／🔵 區分熱度

> [!quote]- 💎 鑽石
> 沉澱出來的領悟／價值觀／能力
> - 月度回顧時 AI 從這裡撈候選 → 認領 → DASHBOARD 累積層

---

## 📝 工作日誌

------------` YYYY-MM-DD `------------

【 焦點 】
【 過程 】
【 結論與下一步行動 】
```

### 跟工作 WORKBOOK 的差別

| 工作 WORKBOOK 有 | 個人 WORKBOOK 改成 |
|---|---|
| frontmatter 帶 `orbit` | 拿掉（不用燈號） |
| 願景＋目標（同向） | 🌅 嚮往端 vs 🌑 心魔端（兩端對立） |
| 思考中 | 🌀 擠壓中 |
| 領悟 | 💎 鑽石（月度回流到累積層） |
| 📅 Timeline | 拿掉（個人專案沒明確時程） |
| ℹ️ 會議記錄 | 拿掉 |
| ▋ 目前產出 | 拿掉（鑽石就是產出） |

## 5. 生活雜事規則

### 死線格式

每項雜事都要有死線——**沒有時程壓力的雜事不會被做**。

DASHBOARD 上以表格形式呈現：

```
### ▋ 生活雜事

| 項目 | 死線 | 備註 | 狀態 |
|---|---|---|---|
| 換駕照 | 5/20 |  | ⬜ |
| 退衣服 | 5/12 |  | ⬜ |
| 約看牙醫 | 5/30 | 這個月內處理 | ⬜ |
```

死線欄位用 `M/D` 即可。剩餘天數由 AI 在開工／更新時動態算（不寫進靜態檔案，避免每天要更新「剩 X 天」這種雜訊）。狀態欄用 emoji：⬜ 待處理／✅ 已完成。

### 過期處理

雜事過期時 AI 主動問——

```
看到「退衣服」（死線 5/12）已經過期 3 天，要：
- A. 延期（給新死線）
- B. 直接刪掉（不做了）
```

不自動處理——保留判斷摩擦給使用者。強制處理會讓人不敢往池子裡加東西，眼不見為淨會讓死線失去嚴肅性。

### 完成後

打勾後保留在 DASHBOARD「✅ 已完成」區塊（看得到成就感），fu-pan 復盤時順手歸檔超過一週的已完成項目（搬到當週 STATUS LOG 或刪除）。

### 跟 kai-gong 開工的配合

每天開工時，AI 從生活雜事池子選**時程壓力最大的一條**，加進今日焦點：

```
今日生活雜事：[ ] 退衣服 ⏰ 5/12（剩 3 天）
```

選擇邏輯：剩餘天數最少（過期 = 負數，最優先）。

每天只指派一件——呼應 [[【 D. 專案筆記：工作禪系統 】]] 的領悟「**專案只留一個下一步行動，多個待辦只會帶來焦慮**」。

## 6. 資料流

### 鑽石流向（核心資料流）

```
個人 WORKBOOK 💎 鑽石（隨時累積）
       ↓ 每週復盤（fu-pan SKILL）
       ↓ AI 從鑽石＋自由寫作＋STATUS LOG 撈候選
       ↓ 使用者認領（要／不要／改一下）
       ↓
DASHBOARD 累積層 🚫 我不要的／🔥 我活出來的
       ↓ 累積一段時間後
       ↓
回頭修改定義層 🪞 我是誰／🧭 生命觀
（極慢的迴圈——可能一年才動一次）
```

### 「我喜歡自己的什麼」流向（自我描述累積）

```
自由寫作裡的「我喜歡自己的三件事」
       ↓ free-writing-extract（整理自由寫作時）
       ↓ append 到 [[【 F. 我喜歡自己的什麼 】]] 累積檔（原始 entry，最新在上）
       ↓ 每週復盤
       ↓ fu-pan 讀本週新增 entry，萃取成「自我描述」（凝練觀察）
       ↓
個人 DASHBOARD「🪞 最近的我」「▋ 最近喜歡的自己」（覆蓋上週的自我描述）
```

⚠️ free-writing-extract **只寫累積檔，不寫 DASHBOARD**——DASHBOARD 只放萃取結果（fu-pan 處理）。

### 其他寫入

| 來源 | 寫入位置 |
|---|---|
| fu-pan（每週日復盤） | 個人 DASHBOARD「🪞 最近的我」（本週咒語＋從累積檔萃取的自我描述）＋ 累積層「🚫 我不要的／🔥 我活出來的」（從鑽石撈候選認領）＋ 生活雜事歸檔（清理「✅ 已完成」） |
| kai-gong（每天開工） | 軌道圖今日焦點：今天指派的雜事（從個人 DASHBOARD 撈剩餘天數最少的一條） |
| shou-gong（每天收工） | 個人 DASHBOARD「📋 生活雜事」：把今日焦點打勾的雜事搬到「✅ 已完成」 |
| free-writing-extract（自由寫作整理） | 個人 DASHBOARD「📋 生活雜事」（自由寫作裡有提到生活雜事時）＋ [[【 F. 我喜歡自己的什麼 】]] 累積檔（自由寫作裡有「我喜歡自己的三件事」格式時） |

## 7. SKILL 協作

個人專案系統不獨立 SKILL——所有整理動作都整合進現有儀式 SKILL（kai-gong／shou-gong／fu-pan）。

### fu-pan 整合（每週復盤時整理個人 DASHBOARD）

復盤本來就在掃整週狀態，順便把個人 DASHBOARD 的整理一起做掉——至少一週整理一次累積層，不用等月底。

**新增步驟**：在 fu-pan 既有的「本週分析」之後加一段「個人 DASHBOARD 整理」：

```
1. 累積層二問
   AI 從本週自由寫作＋STATUS LOG 身心＋收工小心得＋個人 WORKBOOK 💎 鑽石
   每個區塊提 2-3 個候選（附原文出處）

   🚫 我不要的——「這週有確認『不是我』的東西嗎？」
   🔥 我活出來的——「這週有沒有讓你覺得『這就是我』的事件、句子、或能力？」

   使用者逐條認領（要／不要／改一下）
   → 寫入個人 DASHBOARD 對應區塊

2. 自我描述萃取（「▋ 最近喜歡的自己」）
   AI 讀本週 [[【 F. 我喜歡自己的什麼 】]] 累積檔的新 entry，
   萃取成 1–3 句自我描述（凝練觀察，貼近使用者語氣，不過度詮釋）
   → 覆蓋寫入個人 DASHBOARD「🪞 最近的我」的「▋ 最近喜歡的自己」

3. 生活雜事歸檔
   掃個人 DASHBOARD「✅ 已完成」區塊，超過一週的搬到當週 STATUS LOG 或刪除
```

「🪞 最近的我」的咒語＋自我描述都不需要明確清空——下週復盤寫入時自然覆蓋。

### kai-gong 整合（每天開工讀生活雜事）

開工 SKILL 每天做兩件事：

1. **撈最緊一條雜事進今日焦點**：讀個人 DASHBOARD「📋 生活雜事」，計算每條剩餘天數，挑剩餘天數最少的一條（過期 = 負數，最優先）寫進開工報告
2. **過期雜事處理**：在「一次問完」階段加上——「看到 X 已經過期 N 天，要延期（給新死線）還是直接刪掉？」由使用者判斷

### shou-gong 整合（每天收工同步雜事勾選）

收工時，使用者在軌道圖今日焦點打勾的雜事，要同步回寫到個人 DASHBOARD：把「📋 生活雜事」表格中對應 row 移除，搬到下方「✅ 已完成」區塊（格式：`- {名稱} ✅ M.D`）。在 shou-gong 既有的「今日焦點 checkbox 追蹤」步驟順手做。
