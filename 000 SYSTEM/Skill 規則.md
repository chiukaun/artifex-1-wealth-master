
### Skill 修改同步規則

每次修改任何 Skill 檔案（`.claude/skills/` 底下）的**行為或流程**（新增步驟、改順序、改寫入規則等），必須同步更新：

1. **`000 SYSTEM/000 Skill 更新回饋.md`**——在對應 Skill 的 callout 中新增調整紀錄，並更新底部更動紀錄表。
2. **`000 SYSTEM/000 工作專案系統藍圖.md`**——如果改動影響資訊流方向、SKILL 清冊、命名規則、設計哲學等，同步更新對應區塊。

只改文字表述、修錯字、調格式的不用更新。

### Skill 通用規則

以下規則適用於所有 Skill，不需要在各 Skill 中重複寫。各 Skill 的「注意事項」只寫該 Skill 獨有的規則。

1. **先讀再改**：更新任何檔案前，先 Read 確認現有內容與格式，再用 Edit 修改
2. **全形標點**：中文文本一律全形標點（見上方「關鍵規則」）
3. **語氣自然**：像 MSN 聊天室那樣說話（見上方「核心語氣」）
4. **搬移確認**：搬移資料夾或檔案時，先確認目標路徑存在
5. **寫入後連結**：寫入完成後，列出更新文件的 `[[wikilink]]` 讓使用者跳過去確認
