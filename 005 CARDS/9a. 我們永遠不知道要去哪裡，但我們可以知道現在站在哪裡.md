
如果循環一定會發生、而且沒人猜得到什麼時候轉向，那我們到底能做什麼？

Howard Marks 說有三種選擇，而前兩種都不好：

**第一種**：加倍努力去預測。但幾十年的資料跟他自己的經驗都說：關於循環，唯一能預測的就是「它一定會發生」。

**第二種**：既然不可知，乾脆完全不管。買了就放著，不管市場現在是瘋狂還是絕望。

**第三種**（他認為好非常多）：**不預測未來，但搞清楚現在的位置。**

他把這件事講得很斬釘截鐵：

> **「我們也許永遠不知道要去哪裡，但我們最好知道自己現在在哪裡。」**

而這裡藏著一個常被忽略的分別：**預測未來很難，但看懂現在一點都不難。**

你不需要任何預測能力，只需要張開眼睛看看四周，然後推論（inference）。Marks 提供了一份很實用的清單，他叫它「窮人的市場評估指南」——每一組挑一個比較貼近現況的：

| | 左邊 | 右邊 |
|---|---|---|
| 經濟 | 熱絡 | 遲緩 |
| 放款機構 | 急著借你 | 縮手 |
| 資金 | 充沛 | 稀缺 |
| 借款條件 | 寬鬆 | 嚴格 |
| 利率 | 低 | 高 |
| 投資人 | 樂觀、急著買 | 悲觀、沒興趣 |
| 資產持有者 | 抱得很爽 | 搶著出場 |
| 賣方 | 很少 | 很多 |
| 市場 | 擁擠 | 乏人問津 |
| 基金 | 想進去要排隊、天天有新的 | 只有最好的募得到錢 |
| 近期績效 | 強 | 弱 |
| 資產價格 | 高 | 低 |
| 預期報酬 | 低 | 高 |
| **風險** | **高** | **低** |
| 受歡迎的特質 | 積極、廣撒 | 謹慎、精挑 |

Marks 的結論很簡單：**如果你的勾大部分落在左邊那欄，把你的錢包看緊一點。**

請注意這張表最有趣的地方：**「資產價格高」跟「風險高」是排在同一欄的。** 也就是說，當所有東西看起來最美好、最讓人放心的時候，正是風險最大的時候。

而這整張表，沒有任何一格需要你猜未來。
